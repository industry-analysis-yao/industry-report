# Industry Report

大王製紙向けの家庭紙・衛生用品・関連設備の情報ダッシュボード。

## 収集・選定（2026-09-08 更新）

- 日本メーカーの公式発表を直接収集：ユニ・チャーム、日本製紙（クレシア含む）、花王、大王製紙、王子ホールディングス、瑞光。
- Google News RSS は補助的な発見経路。RSS 日時だけでは日報に採用しない。
- 公式一覧では、同じ行／JSON レコードのタイトル・リンクに結びついた公開日だけを採用する。日本製紙は `pub_on`、花王はニュース索引の `time`、HTML は各発表行の表示日付。`mod_on`、サイト構築日時、PDF 更新日時は使わない。
- 本文の明示的な初回公開日が一覧より古い場合は古い日付を優先。本文取得不能・原文日付未確認は日報対象外。PDF は最初の4ページまでを抽出し、日付は公式索引の公開日を保持。
- 30日間の過去日報との URL・指紋・類似タイトル／記事内容による照合を通過した候補から、目標20件を選ぶ。同日再実行はその日の既刊分を重複扱いしない。
- 直近14日を優先し、不足時は未掲載の15〜30日、最後に31〜60日の候補を検討。低頻度の設備・ウェット・家庭紙枠は30日以内の未掲載分から先に確保。日報の日付と原文公開日は別物であり、再取得しても公開日は変更しない。
- 特許は別枠。製品ニュース内の「特許技術」という表現だけでは特許公開として扱わない。
- 化粧品・ペットフード・スポーツ等は公式サイトの掲載であっても対象外。メーカーの事業・工場・原材料・関連技術は対象。

## 要約・スコア

`OPENROUTER_API_KEY` が設定されている場合はAI要約・審査を行う。利用不能／予算上限の場合も、検証済みの原文を捨てず、**原文抜粋・ルール評価**と明示する。AI分析を捏造しない。

ルール評価は関連性（最大35）・影響度（最大28）・出典信頼性（最大20）・鮮度（最大15）の合計。各内訳は `score_components` に保存する。AI評価と異なる方式であり、絶対的な精密評価ではない。

## 実行・検証

```sh
pip install -r requirements.txt
python -m unittest discover -s tests -v
python scripts/fetch_news.py --dry-run --json-output work/fetch-preview.json
python scripts/fetch_news.py
python scripts/generate_dashboard.py
python scripts/validate_digest.py
```

`--query-limit 0` は公式メーカーと特許だけの試験、`--no-enrich` は本文取得を省く調査用。定常運転で本文取得を省略しない。

GitHub Actions は毎日07:05 JSTに実行する（スケジューラによる遅延はあり得る）。RSS 本文確認枠は100件で、確認済みの既知リンクは枠を消費しない。

## 数量不足の診断

- `data/collection_health.json`：取得日時、各公式サイト・RSSの候補数、失敗、日付確認済み件数。
- `data/YYYY-MM-DD.json` の `selection_health`：採用数／目標、確認済み候補、30日履歴との重複、AI対象外判定、排他的な分野別件数。
- 20件未達は Actions 警告と実行サマリーに表示する。候補不足の理由を隠さない。

20件は収集・選定目標であり、毎日20件の新発表があることは保証できない。不足時に既刊の再掲や旧記事の日付改変はしない。公式サイトの構造変更・取得失敗は診断ファイルから検出し、ソースを修正・拡充する。
