# 日次レポートの編集方針（2026年9月30日改定）

## 対象

大王製紙の競合・取引先を中心に、日本の衛生用品、家庭紙、ウェットワイプ、不織布・吸収体加工、包装設備の公開情報を収集する。外国企業の関連技術も補完的に確認する。

「パレタイザー」は積付け、段積み、パレタイズ、デパレタイズ、荷下ろし設備を指す。単に robot / ロボット / AI と記載された記事は、この区分に入れない。箱詰め・袋詰め・包装ライン向けのロボットは包装設備に分類する。

汎用ヒューマノイド、Physical AI、ロボット基盤モデル・一般的な制御装置・研究用ロボット・工場巡回ロボットは、包装ラインや積付けでの具体的用途が原文にない限り対象外。会社紹介や記事末尾の関連リンクだけでは用途の証拠としない。

## 件数と鮮度

- 目標は平日20件。カテゴリー別の目安は競合・メーカー6、加工機3、包装4、ウェット2、家庭紙2、トイレットペーパー1、パレタイザー2。
- 上記は配分の目安であり、最低件数の保証ではない。不足枠には他分野の適格記事を採用できる。対象外のAI記事や古い記事では補充しない。
- 原文公開日は直近3日を優先し、最大でも当日を含む5暦日以内。展示会の会期・発売予定日・更新日を公開日へ置換しない。
- 過去30日間の掲載履歴と、同日の候補同士を照合する。日付やURLが違っても同じ事件の転載は重複対象。
- 特許は企業の公開情報を別の蓄積欄で扱い、日次ニュースの20件に混ぜない。
- 収集数、日付未確認、期限外、重複、対象外、採用数を診断データで区別する。

## 取得と配信

メーカーの公式ニュース索引と企業別PR TIMES配信を優先する。PR TIMESのRSS 1.0でdc:dateがupdatedとして解析される場合も発見対象とするが、その日付だけでは公開日確認済みにしない。本文の公開日を別途確認する。

「おしりふき」「吸水ケア」「ティシュ」等の表記差と、「リニューアル」も発見対象に含める。これらが不足していたために、企業の正式な新商品発表を見落としていた問題を修正した。

収集・下書き作成は日本時間19:35を予定時刻とし、GitHub Actionsの待ち時間により遅延する場合がある。下書き生成は平日1日1回、休日は収集のみ。OpenRouter（DeepSeek）は下書き作成を補助できるが、自動的には公開しない。手動実行の有料API利用は初期状態で無効。

最終編集・原文照合・不足分の追加検索・全日本語化・掲載判断はCodexが担当する。Codexの承認前は直前の公開版を維持する。公開時には、下書きの提供元とCodexの承認記録を区別して保存する。詳細は [Codex承認後の配信手順](codex-review-publishing.md) を参照。

過去の公開版は履歴として保存し、今回のルール変更で過去の日報内容や件数を遡って書き換えない。新しい配信から新方針を適用する。
